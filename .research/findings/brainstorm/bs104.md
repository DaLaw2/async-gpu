# BS-104 Synthesis: ONNX Loader, Larger Training, GPU Memory Pool

## Consensus

Both proposer and skeptic agree on:
1. **Memory pool has minimal impact** (~0.2-2.3% of runtime). Measure-only, don't build.
2. **ONNX is out of scope** — op coverage is a bottomless pit, not aligned with project identity.
3. **The real blockers are in backward/optimizer infrastructure**, not model loading.
4. **Conv2d backward only computes dInput, NOT dWeight** — critical gap for CNN training.
5. **CrossEntropy backward is not wired into the tape** — blocks end-to-end autograd training.
6. **Optimizers do CPU roundtrips** — should be GPU-side kernels.

## Disputes

| Topic | Proposer | Skeptic | Resolution |
|-------|----------|---------|------------|
| SafeTensors generic loader | Build it (16h), enables new models | Defer — just moves hardcoding, no real user demand | **Defer** — fix autograd foundation first |
| GPT-2 LoRA training | Feasible, 18h | Realistic 35-40h, needs CrossEntropy+optimizer first | **Proceed with prerequisites** — fix foundation, then LoRA |
| Memory pool | Slab allocator, 8h | Skip — 0.2% impact not worth complexity | **Measure only** (2h), skip if < 5% |

## Agreed Priority

1. **Fix autograd foundation** (highest impact, enables everything downstream):
   - Wire CrossEntropy backward into tape dispatcher
   - Implement GPU-side SGD/Adam kernels (eliminate CPU roundtrip in optimizer)
   - Fix conv2d backward to compute dWeight (not just dInput)
   - Pre-pad weights once (eliminate per-forward reshape overhead → close 2.4x nn-perf gap)

2. **GPT-2 LoRA fine-tuning example** (after foundation):
   - Freeze all layers except LoRA adapters
   - Train on a small text dataset
   - Showcases: autograd + GPU training + real NLP task

3. **Measure memory pool overhead** (quick spike):
   - Instrument cudarc alloc/free timing
   - If > 5%: build slab pool. If < 5%: skip.

4. **Generic SafeTensors loader** (defer):
   - Only build when there's a concrete new model to support
   - Not a priority until autograd is production-quality
